# GitSetup 🛠️

**GitSetup** is a robust, modular, and non-destructive CLI tool designed to automate the configuration of your Git and SSH environment on macOS and Linux. It simplifies the management of multiple Git identities (e.g., Work vs. Personal) and ensures your development environment is consistent and secure.

## ✨ Features

- **🚀 Automated Setup**: Configures global `.gitconfig`, `.gitignore`, and Git hooks in seconds.
- **🔐 Dynamic SSH Management**: Automatically generates SSH keys and configures `~/.ssh/config` for multiple providers (GitHub, GitLab, etc.) without overwriting your existing configurations.
- **🆔 Multi-Identity Support**: Automatically switches Git user/email based on the repository remote URL (perfect for mixing work and personal projects).
- **🛡️ Secure & Safe**: 
  - Non-destructive updates to SSH config (uses smart markers).
  - Prompts before overwriting existing configurations (Interactive Mode).
  - Checks for dependencies (`git`, `ssh-keygen`, `envsubst`).
- **🧹 Cleanup Mode**: Easily remove all configurations generated by the tool.

## 📋 Prerequisites

- **OS**: macOS or Linux (tested on MacOS 26.2)
- **Shell**: Bash (tested with Bash 3.2.57)
- **Dependencies**:
  - `git` (tested with Git 2.51.2)
  - `ssh-keygen` (OpenSSH)
  - `gettext` (for `envsubst`)

### Install Dependencies (macOS)
```bash
brew install git gettext
brew link --force gettext
```

## 🚀 Installation & Usage

1. **Clone the repository**:
   ```bash
   git clone https://github.com/henchoznoe/GitSetup.git
   cd GitSetup
   ```

2. **Configure your environment**:
   Copy the example configuration:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` with your details:
   ```bash
   # Your Name
   GIT_USER_NAME="John Doe"
   
   # Default Email
   GIT_USER_EMAIL_DEFAULT="no-reply@example.com"
   
   # Profiles: host:email,host:email
   # This will confuse SSH keys and Git hooks for auto-switching
   GIT_PROFILES="github.com:personal@gmail.com,gitlab.company.com:pro@company.com"
   ```

3. **Run the setup**:
   ```bash
   chmod +x ./bin/git-setup
   ./bin/git-setup
   ```
   *Follow the interactive prompts.*

### Options

| Flag | Description |
| :--- | :--- |
| `-d`, `--dry-run` | Simulate the process without making any changes. |
| `-y`, `--yes` | Skip confirmation prompts (Non-interactive mode). |
| `--clean` | Remove all configurations and keys generated by GitSetup. |

### Example: CI/CD or Automated Install
```bash
./bin/git-setup --yes
```

## 🏗️ Architecture

- `bin/git-setup`: Entry point.
- `lib/`: Modular logic (SSH, Git, Utils, Logger).
- `config/`: Templates for global git configuration.
- `tests/`: Functional tests.
